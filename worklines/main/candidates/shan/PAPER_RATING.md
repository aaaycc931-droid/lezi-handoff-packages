# 山｜8回合／3次特殊应将／5次有效将军｜首轮条件性纸面评分

日期：2026-10-21（Asia/Shanghai）。来源基准：`50943f7451a6da88da2791b702f52138376d964b`。本轮授权：“现在进行本轮评分”。

**本轮参考情景估分：R≈46/80，S≈57.5/100（约58分）；置信度低。** 较高成本到较低成本情景约47.5–67.5分。该区间是主观情景包络，不是统计置信区间或已验证上下界，不排除完整参数或实际对局使结果超出此范围。

本次采用原评分方法的五维、A–L和80→100归一化；因完整死亡概率表、祭品表及对局状态概率尚缺，尚未完成完整状态树的概率加权期望。各项分数是同一AI对明确条件情景的判断，不能解释成实战胜率、实测模型输出或完整数值版的最终评分。没有从临时8/10、7/10转换或以历史英雄分数作目标。

## A．本轮评分输入与状态

| 内容 | 状态／本轮采用 |
| --- | --- |
| 主帅不能移动 | 本会话已确认 |
| 特殊应将 | 献祭或赌命，换取一着其他棋子的正常行动；本手结束允许主帅仍受攻击，下次受将重新应对 |
| 行动数 | 每次仍只有一着普通行动；献祭是成本，不额外赠送移动或进攻 |
| 压力 | 献祭不清除；新有效将军升压，持续旧威胁维持；敌方行动后真正不受将时逐渐下降 |
| 死亡后倒计时 | 8个己方行动回合 |
| 死亡后特殊应将 | 3次；献祭和赌命都消耗额度，不补充或刷新 |
| 影武者斩帅 | 死后累计5次有效将军；正常将死仍直接获胜 |
| 公开与私密 | 敌方看棋步、献祭与将军；真实生死、死后额度／剩余时间和斩帅进度不公开 |
| 死后提前败亡 | 额度用尽后再遇受将，若不能普通解将则立即败亡 |
| 当前缺失 | 各压力档死亡概率、祭品最低等级与资格范围；有效将军去重及部分跨阶段结算边界 |

本轮时序假设：导致秘密死亡的那次特殊应将不占死后3次额度；8回合从后续己方回合计；斩帅从死后下一次己方行动起累计，死亡当次不追溯计数。前两项继承早期候选解释；斩帅跨死亡当次的计数边界没有取得足够明确的确认，作为本轮假设保留，不能据此改正式规则。第8个己方回合内达成胜利先按胜利结束，否则回合末山崩；这个先后也应在后续规则快照中明确。

不假定特殊应将免除其他所有走子条件；本轮无额外畸变、强制位移、范围消灭或额外行动联动。祭品先移除后的棋盘变化真实生效，不把已献祭棋子继续作为炮架或挡子。基本走法、普通解将与对手必须回应将军等沿用当前项目规则；本次没有验证全部跨模式交互。

## B．反事实基线

对照同一模式、相同棋盘与玩家熟练程度，移除山的整个英雄机制，恢复普通将帅移动、应将与终局条件。帅位不动是山的成本，应一并纳入，不能把“没有山技能但主帅仍不能动”当正常基线。

只计算新增边际：本来就能普通解将／将死的局面，不把整次胜利再次归功于技能。对手按熟悉全部公开规则、正常熟练但非完美AI处理；不因预设敌人一定误判生死而额外加分。

## D．状态树与时序

- 存活且不受将：正常行动，主帅仍不可移动。
- 存活且受将：普通解将，或特殊应将。献祭支付真实子力成本；赌命按当档风险分为仍存活／秘密死亡。
- 秘密死亡后：初始剩余回合8、特殊应将额度3、斩帅进度0（按本轮时序假设）。可普通解将，也可支付一次额度继续其他行动。
- 后续每个有效将军按去重规则累计；达到5则胜；正常将死也胜。
- 额度归零并不当场失败。再次受将且无法普通解将时失败；未获胜且第8回合结束则失败。

计数核对：3次额度分别用在死后第1、2、3次必须特殊处理的应将；第4次此类威胁才因缺少额度而无法继续。若山每次同时反将，前三手斩帅进度最多3；第4次威胁不能普通解决时，会在达到5次之前被击破。这是条件式计数推演，不是已验证存在完整合法棋谱。

8回合内从0累计5次，最多容许3个没有有效将军的己方行动回合。不能把8回合当8次免死，也不能把5/8解释为胜率。

## E．直接兑现

最高价值分支是：原局面不能普通解将，山以子力或随机风险换取本手反击；后续在兵力仍足时获得普通将死或5次将军胜利。一次救命和最终胜利若来自同一决策分支，按整条分支的反事实净变化处理，不把多个“胜利价值”相加。

失败分支包括：关键祭品削弱后续进攻、赌命过早进入倒计时、剩余军队缺乏持续将军、第四次必须特殊处理的威胁提前击破，以及8回合耗尽。主帅固定也会使某些正常可移帅化解的局面变成需要支付成本的局面。

## F．对手规避与反制

两条主要反制仍有效：持续制造必须支付额度的威胁，或削弱山的进攻兵力、避开有效将军并拖过死战窗口。隐藏生死会改变对手决策，但熟悉规则的对手可以保留不确定性，不必按“赌了几次就一定死了”行动。

规避与直接兑现按互斥分支看：敌人为了避免山反将而改变阵形的损失，不能与同一窗口内本来假设已经完成斩帅的收益重复满计。隐藏进度的公平性、有效将军的去重仍是关键风险。

## G．局长与生命周期敏感度

按原法以30个完整双方回合为中心，并检查25／35回合变化：

| 局长 | 本次检查结论 |
| --- | --- |
| 25回合 | 可用于组织进攻、积累压力和支付献祭的窗口较少；若山很早秘密死亡，其死战窗口仍只有8个己方回合 |
| 30回合 | 采用参考情景；需要同时覆盖生前普通防守、赌命／献祭与死后反击，不能只评最好一次死战 |

净方向依赖秘密死亡发生时点、兵力分布、受压频率和各档成本，当前不能据此给出可靠的三个局长中心分。这项敏感度已作机制检查，数值化仍未完成；没有编造局长收益系数。

## H．联动与替代

本轮只评基础英雄能力；不预加额外行动、改变进攻几何、复活、范围消灭、返位等畸变联动。额外行动可能加速5次斩帅，强制位移／范围消灭可能绕过目前特殊应将假设，均需分开核查；现有候选不据此获得额外分数。旧“风”与新“山”不合并，也不沿用其旧分数。
