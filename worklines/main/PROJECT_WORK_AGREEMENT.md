# 主线工作约定

本线负责共享规则与裁判协调；普通、半混乱、UI保留各自已有独立任务。当前阶段为设计与来源核对，评分冻结、NET暂停。业务确认由ADJUDICATION.json及其明确来源控制，候选只在PENDING_DECISION.json保持pending。

恢复依据为本账号既有主线1.49原件、2026-10-15四线归并快照及当前远端入口。原1.48归档、旧暂停和旧协作版本保持历史身份，不覆盖较新的确认。当前协作版本从../../collaboration/CURRENT.json解析。

先恢复正文与确认，再推进最小差分。新游戏机制须得到指向具体方案的确认；接续指令只恢复工作。主线可以在已有授权内整理本线、来源索引、规格和共享协调，不改其他线未回传工作稿，不替接收方写采用回执。主线向各线公布共享协调，接收方在自己的目录记录实际阅读与采用。

局部改动检查本体及直接依赖；关键共享变更核对时序、权限、合法性及作用域。复用仍有效的历史证据，文件/哈希检查不算游戏运行通过。设计确认、文档归并、实现、运行验收、发布、接收、采用分别记录。

本次固定入口发布只覆盖恢复主线接续所需正文、状态、确认来源和协调项；不声称完整历史档案或半混乱全线已迁移。只在任务确需时恢复深层来源，缺口只阻断相应依赖。

阶段完成、共享阻断或用户收束时更新本目录及RETURN_TO_MAIN.json；通过GitHub连接器按../../docs/WORKFLOW.md增量写回，基准校验且不强制推送。无游戏源码实现、APK、部署、历史重写或自动向其他对话发消息的授权。
