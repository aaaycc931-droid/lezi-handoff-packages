## CASE-H05-01｜旧线实际吃子，新线不吃子（标准开局可重放前缀）

坐标：红方底线为行 1、黑方底线为行 10；列 1—9。红方英雄假设 H05。

| 回合 | 32 棋常规真实走法 | 吃子 |
|---|---|---|
| 红1 | 红兵 (5,4)→(5,5) | 无 |
| 黑1 | 黑卒 (5,7)→(5,6) | 无 |
| 红2 | 红兵 (5,5)→(5,6) | 消灭黑卒(5) |
| 黑2 | 黑马 (2,10)→(3,8) | 无 |
| 红3 | 红兵 (5,6)→(5,7) | 无 |
| 黑3 | 黑马 (3,8)→(5,7) | 消灭红兵(5) |
| 红4 | begin 前，H05 发动窗口 | 待重演 |

旧线黑3仅执行一次主动Ⅰ级【进攻】，符合 H05 历史回合行为门槛（在此例不设额外主动技能）。H05 从黑3 **begin 前**锚点重演，允许黑马重新选普通Ⅰ级【移动】 (3,8)→(2,10)，不吃红兵。黑马从(3,8)退回(2,10)不受马腿阻挡；新线双方将帅安全。前缀全部走子在独立小校验器通过；旧线棋子数30、新线31，恢复了旧黑3所吃的一枚红兵。

**规则所要求的预期（未引擎执行）**：
1. 新棋盘保留红兵(5,7)，当前权威“已消灭棋子记录”不得继续包含该存活红兵；历史黑3吃子事件审计允许留档。
2. 原黑3本来已被正式接受，其对“无吃子计数、长将/长捉压力计数重置、重复局面统计段”等外置裁判历史效果不能被纯恢复机械回滚。恢复红兵本身不是第二次【消灭】。
3. 黑3重演不再增加一个黑方正式回合；红4 H05成功后占用一正式行动机会、永久扣唯一技能，跳过红4 begin/end。后续轮到黑方。
4. 现行裁判确认：真实消灭重开重复统计段；单纯历史恢复不撤销该段、恢复自身不再重开。该规则已确认设计但未实现；不可误标“裁判 PASS”。

**真实检查**：普通几何、马腿、起终点占位、双方将帅安全、两条分支存活数通过。**未检查**：H05 原子/裁判独立账本真实运行。

## CASE-H05-06｜长将/长捉第7次、重复第5次与事件去重（裁判压力测试规格，未构造可达前缀）

**已确认独立裁判规则**：
- 同方连续正式将军最多6次，第7次符合禁将条件的候选拒绝；长捉同方同稳定棋目标最多6次，第7次禁着；多枚攻击棋切换不自动清零。
- 已接受的真实吃子或技能【消灭】重置双方既有长将/长捉序列；动作若在重置后仍有符合来源的压力，新序列从1开始。拒绝动作/被阻挡的进攻不重置。
- 重复局面累计达到5次（含首次），匹配同模式、轮到哪方、合法稳定采样阶段与共同公开有效状态；单纯时间回溯不额外采样，也不能回滚当前重复统计。真实吃子导致的新重复统计段不能被恢复撤销。内部棋子ID不应单独令相同公开局面不等。
- 行动链必须在来源允许的正式稳定终点完成采样，不得在中间步骤多算；既有【终结】优先。
- 裁判约束来源 `ADJUDICATION.json` 的 `unified_adjudication_core` 子项已确认设计，**不是**引擎实现。

**尚不能写成成功的 H05 测试**：
1. 旧黑方压力记录6，H05替换上一步使新线不产生该压力，旧账本的连续属性与新线事件如何合并？在什么正式稳定点判第7次？
2. 旧历史【消灭】已重置压力与重复统计段，新线同回合再发生一次不同【消灭】，两个被接受事件如何去重/排序；新线不消灭却已留下旧重置时如何更新新局面。
3. H05当前红方【占步】虽然无普通棋行动，究竟是红方独立压力序列的“本回合无将/无捉”采样还是存在来源特殊样例？不能机械以黑方重演原子中间压力归给红方。来源未给完整 H05 专属归因接口。
4. H05重演成功的原历史同一正式回合，对重复键/压力是否进行“旧结果替换”与“保留审计”双记录，且仍只形成一个正式回合采样；需原子ID与裁判责任方确定。
5. 仍需构造真实可达的长将第6→7、同目标长捉第6→7、相同公开状态的第4→5局面，才能进行裁判实际反例测试；本轮没有运行这些样例。

## CASE-H05-07｜隐藏信息、自动重随机、合法不利结果（待构造）
