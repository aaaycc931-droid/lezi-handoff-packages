## 二、H01 猎人｜保留的设计方向

**设计确认：**
- **里形态：陷阱伏击。**保留原有陷阱机制，不在本轮修改原规则。
- **表形态：弓箭狩猎。**引入弓箭式远程狩猎的新能力，强调与陷阱不同的主动进攻体验。

**尚未确定：**箭矢由哪枚棋子或英雄发动、射程、攻击方式、目标规则、使用次数、形态切换等。先保留概念，不得当作定稿。

## 三、H02 潜行者｜保留两种暗影步方案

**双形态方向：**灵动侧发展“暗影步”，冷酷侧保留既有刺杀机制。旧刺杀正式规则不因此改变。

**方案 A｜主动回退（用户已选定其内部处理方式）**
- 只能回退**己方**棋子的行动，不能回退敌方棋子。
- 已选择**位置回退**而非完整行动撤销：棋子位置退回，之前已经造成的吃子等结果**保留**。
- 发动时机、次数、合法性与其他限制待定。

**方案 B｜兵卒被动后撤（独立保留，不与 A 自动合并）**
- 己方兵卒成功向前**移动**后，获得在下一次**移动**中向后退一格的机会。
- 后退属于移动，不是攻击；须满足合法性与己帅安全。
- **允许循环触发**：新的前进移动可以再次获得后撤资格；后撤本身不生成新的后撤资格。
- 过河条件、触发时序的细节等待定。

**状态说明：**A 与 B 均应保存为设计可能性，尚未决定最终采用一个、两个并用或如何安排。

## 四、H03 战士｜表里双形态（本轮重点，已讨论至 V1.9 + 怒气机制 V1.5）

### 4.1 职业定位与技能演出【已确认方向】

- **里形态：坚守／防御。**沿用战士原有普通防御、将帅铁甲，原机制规则以项目既有文本为准，不在本稿改写。
- **表形态：打击／进攻。**核心技能暂名 **「战斧劈砍」**。
- 战士定位为《乐子象棋》中**首个以英雄技能实现棋盘外与棋盘内动画交互**的英雄：战士从棋盘外召唤具有实体长方形体积的巨斧，直接劈砍棋盘区域。
- 这不仅是棋子普通吃子动画，而是英雄来源、视觉上跨棋盘内外的技能。借鉴“英雄亲自挥斧砍入棋盘”的表现思路，但不直接照搬他人现有画面素材。
- **暂时不设计冲锋**；怒气已重新引入，但仅用于战斧的释放距离成长，不附加此前未确认的怒气攻击技能。

### 4.2 固定四点劈砍几何【已确认并纠错】

玩家选择**一个格子作为中心格**；打击体积纵向覆盖中心格、上格、下格，合计**连续三格的高度**。实际受击的**棋盘交叉点只有四个**：

1. **上格的右上角**；
2. **中心格的右上角**；
3. **中心格的左下角**；
4. **下格的左下角**。

这四点对应用户讨论中称的 **1—4 号位置**。巨斧具有长方形实体打击体积，位于四点构成的劈砍带中；**不可把整个矩形范围内的其他交叉点自动算作命中**。

**重要纠正：**较早文字曾误记为“中心格左上角、右下角”，用户后来明确更正为**中心格右上角、左下角**。续接必须使用上列四点，不得沿用旧图的错误点位。

**边缘限制【确认选择 A】：**必须能完整形成全部四个命中点且均在棋盘内，才可选择该中心格；不允许边缘裁切后少打几个点。

**方向细节待定：**不同执棋方向时是否镜像／旋转四点图案、左右两侧选格、棋盘 UI 呈现坐标等实现细节尚未专门讨论；不得自行推断新规则。

### 4.3 攻击对象与命中效果【已确认】

- **无差别打击**：四点中无论有己方还是敌方棋子，都受到相同基础结算。
- 命中棋子若存在**本次适用的防御**：**击破防御**，该次命中不直接造成重伤。
- 命中棋子若**没有适用防御**：进入持续 **3 个所属方回合**的**「重伤」状态**。
- **已撤回旧版“命中立即击杀棋子”设想**。现行讨论规则是“破防，否则重伤”。
- 对将帅、不同专属防御、多层防御、无形棋、特殊免疫等复杂规则的适用顺序仍**待定**。

### 4.4 重伤的行动与死亡结算【已确认】

- 被施加重伤时，计时从 **3** 开始。
- 重伤棋子**可以正常行动**；不会在第一次行动时立即死亡，也不会因多次行动叠加“死亡层数”或提前死亡。
- 记录整个重伤期内是否**至少行动过一次**，不以行动次数决定是否死亡。
- **每到该棋子所属方的正式回合结束，重伤剩余回合数减少 1**。
- 倒计时由 1 减至 0 的所属方回合结束时：
  - 重伤期间**一次也没有行动**：解除重伤，**存活**；
  - 重伤期间**行动过至少一次**：在该回合结束时**死亡**。
- 特别强调：某棋子第一回合行动了一次，此后两回合静止，仍然在重伤期满时死亡；即便有多次行动，也不会因此提前死亡。

**同一次战斧同时打中双方棋子的示例：**
- 战士在己方回合、走棋前施放战斧；己方被命中的棋子进入重伤。**战士这个回合结束时**，己方重伤从 3→2。
- 敌方被命中的棋子同样进入重伤，但**敌方完成自己的下一回合时**才从 3→2。
- 双方均按**各自所属方回合结束**独立结算，直至归零。
- **用户已明确确认：**被本回合战斧打成重伤的己方棋子，也**允许立即作为这个回合的走棋棋子行动**；这样会记录“重伤期间已行动”，日后到期死亡，并非当场死亡。

**尚待明确：**强迫移动、英雄技能带来的移动、额外走棋以及棋子被移动但非自身主动行动等，哪些归入“行动过”；再次被打中时重伤是否刷新；重伤中提前被普通吃子或其他机制消灭时如何结算等。

### 4.5 回合／技能时机【用户明确的全局原则】

- **所有英雄技能都只能在己方棋子行动前使用**。
- **所有棋子完成一次正式行动，都会直接结束该回合**。
- 战斧当前按**不占用正常走棋的一步**的技能处理：可在棋子走棋前释放，之后仍能正常走棋；走棋完成之后不能再释放本回合技能。
- “占步／不占步”术语在此前交流中有一次口误或辨认歧义；**执行上以上述先放技能、再走棋、走棋结束回合的明确时序为准**。

### 4.6 战斧次数、初始位置与怒气射程【已确认】

- 战斧**整局只能使用一次**。
- **0 点怒气即可释放**，没有最低怒气门槛。
- **释放时不消耗怒气**；怒气是累计成长值，不是施放代价。
- 怒气**只增加最远可选择的释放位置**，不扩大或改变四点打击形状。
- **初始可达位置的基准**：以己方底线为起点，**斧头第四命中点，即整个范围最右下方的实际命中点，位于己方棋盘底线**。这里的右下角就是四个命中点中的一个，**没有另设一个“不属于命中点的虚拟外边框”**。
- 随怒气增多，整个固定四点形状允许向敌方方向推进。
- **最大射程硬限制**：斧头最前方／顶端的命中点最多到达**敌方九宫格前一条横线**；**敌方最后三条横线均不可受到战斧威胁**。超过此限制不能因为怒气更多而继续向前。
- **暂定成长比例：每累计 3 点怒气，最大可释放距离增加 1 格**。例如：0～2 点 +0，3～5 点 +1，6～8 点 +2，9～11 点 +3；最终仍受敌方后三条横线硬上限约束。
- **怒气没有额外独立上限**；即使射程达到上限，也不因本稿自动设置怒气值上限。

**尚待明确：**“可释放位置”的横向选择如何表述和裁定、不同棋盘朝向的映射、初始允许位置是否存在左右变化及如何标示可选格；具体怒气与棋盘行线坐标之间的实现映射应在后续规则验证中定义。

### 4.7 怒气获取「交战积怒」【已确认的触发框架】

怒气属于战士英雄统一累计，**只因为“真实防御被击破”或“真实棋子死亡”而获得**，不因为普通伤害、重伤状态产生或普通移动而获得。

| 事件 | 怒气 |
|---|---:|
| 己方棋子成功消灭一枚敌方棋子 | +1 |
| 一枚己方棋子死亡（不论死亡来源，包括己方主动牺牲） | +1 |
| 一枚己方棋子的适用防御成功抵挡攻击并被击破 | +1 |
| 某棋子仅进入重伤状态 | +0 |
| 重伤期满而棋子存活 | +0 |
| 重伤期满且该己方棋子实际死亡 | +1（按死亡事件） |
| 普通移动、未击破防御或造成死亡的攻击 | +0 |

- 如果战士进攻形态**通常没有自己的防御**，自然不会触发“被击破防御”的怒气；但若**通过其他英雄、技能或规则实际获得防御**，当防御被击破时仍能获得怒气。
- **己方造成的己方伤亡也允许计怒气**；不禁止主动牺牲。
- 同一枚棋子若先真实地被击破防御，后在其他结算中死亡，可分别基于“击破防御”和“死亡”各获得一次怒气。
- **不重复计数**：敌方棋子被己方棋子吃掉，是一个成功击杀事件，不能又把同一事件以不同名目重复加怒气。
- 重伤与死亡**不分别计怒**：仅仅被战斧打成重伤没有怒气，只有未来真的死亡时才按对应死亡事件计怒。
- 战斧使用完毕后新产生的怒气**不能倒流提高已释放的这次斧击射程**。

**待定边界：**防御损失和死亡同一次连锁结算的先后顺序、对其他来源的无归属死亡如何认定、特殊棋子复活／再次死亡是否重新触发，以及特殊抵挡是否属于“防御被击破”。
