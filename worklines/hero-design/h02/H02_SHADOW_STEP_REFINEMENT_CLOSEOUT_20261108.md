## 一、H02 灵动形态：最新确认机制

### 1. 基本性质与触发

1. 英雄形态方向为己方棋子机动，而非操纵整支棋阵；暗影步是**被动获得的临时走法资格**，不是回溯，也不自动赠送主行动。
2. 当前受潜行者方合法控制的一枚棋子，成功完成一次起点到终点相对行号增加的【移动】或【进攻】，就为**该棋子**获得一次暗影步资格。双方分别从各自底线计算向前；斜向、跨多行只比较行号增减；横向、后退不触发。
3. 【移置】不是【移动】或【进攻】，本身**不产生**暗影步资格，也不因改变位置而自动使用既有资格。
4. 资格允许该棋子在**自己的下一次行动**选择一种新走法：沿所在纵列朝己方底线方向**恰好后退一格**。可作为【移动】或【进攻】，不额外提供行动机会。
5. 这一后退【进攻】具有**独立的一格后退进攻几何**：不必满足原兵种的常规进攻几何。例如原本无炮架的炮，也可通过特殊暗影步直接向后攻击相邻一枚合法敌棋。此为用户明确选 A 的实质新增，不是仅给炮调转方向。原有合法目标、普通防御、龙鳞、封锁、占位、王安全等仍适用；不凭此赋予刺杀特殊的指定无形／绕防御权限，不允许直接吃将帅。
6. 对本来已经合法拥有同样纵向后退一格【移动】或【进攻】走法的棋子，执行该正常合法走法**不扣**三次特殊额度；不产生额外行动。正常走法是否需要在 UI 形式上记为消耗暗影步资格仍属于呈现层待细化。

### 2. 有效期、顺序与刷新（本轮重大时序修改）

1. **有效期从前进行动实际成功完成即开始**，而非必须等到下一己方正式回合才获得资格。额外行动使该棋子在本正式回合再次获得行动机会时，原则上可当回合使用。
2. **最迟到下一己方正式回合结束时失效**；未使用即清除，不跨更晚的正式回合保存。
3. 资格约束的是**该棋子自己的下一次行动**，不是己方阵营的下一次行动。其他己方棋子走一步，不能单凭该行为消耗此棋资格。
4. 若该棋子自己的下一次有效行动是普通移动／进攻而没有选择暗影步，旧资格消耗。若该行动恰又成功向前，则**旧资格消耗、新资格立即刷新**，仍只有一次、不叠加，有效期根据新前进行动延至它的下一己方正式回合结束。若没有新前进则旧资格结束。
5. 之前助手建议的「只要本回合发生过一次前进，无论此后如何行动都保有直到下回合的资格」**已被用户明确否决**，不得复活；也不能改成按整回合净位移判断，因为当前触发仍基于单次成功前进行动。
6. 同一己方正式回合中，**多枚不同棋子**若各自通过允许的动作前进，可以并存各自的一次资格。它们各自的下一次行动／有效期独立；不会额外赠送行动或增加全队预算。

### 3. 资源与拦截

1. 潜行者方**整局共享三次**「需要特殊几何的后退走法」额度，而非每枚棋各三次。
2. **合法发动／实际选择使用特殊走法即扣一次**。即便后退进攻被战士普通防御或龙鳞等合法来源拦截、目标存活、进攻者退回原位置，特殊额度也不返还；实际行动机会按原来源消耗。
3. 非法的行动请求／未被接受的发动，不扣特殊额度；原本本棋可按普通规则执行的同样后退走法免费。具体合法发动以行动真实裁判阶段确认，不把按钮尝试视为消耗；其他特殊失败和落位导致死亡的边界按既有来源核对。
4. 使用特殊暗影步不自动绕过防御、免疫、封锁、隐藏身份保护、将帅安全要求，也不增加主行动数量。

### 4. 将军威胁：用户确认 A 与后续时序修正

1. 用户明确选择 **A：「特殊后退进攻可形成将军威胁」**。但【将军】是合法威胁判定，不等于执行一次【进攻】或准许直接吃将帅。
2. 用户随后明确同意时序：「己方第 N 正式回合向前并取得资格 → 随后敌方回合应对合法威胁 → 己方 N+1 回合使用或到期」。**该时序是原先仅下回合使用时的示例**；本轮更晚的明确修改进一步允许同一己方正式回合经【额外】动作立即使用，所以不能把旧示例错误固化成「必定等到 N+1 才能使用／必定先给敌方完整回合应对」。
3. 因此当前设计应按**资格实际生效的时间段**动态重判威胁：前进行动闭合后可形成合法条件性威胁；使用、被下一次行动消耗、失去控制或期限届满后立即撤销相应临时几何威胁。还有无剩余特殊额度、棋子本身能否【进攻】、是否合法威胁、普通王安全与终局判定均须检查。
4. **需继续专项核对**：在同一正式回合通过【额外】动作立即选择特殊后退【进攻】时，普通将军、应将与候选终局如何依现行裁判原子顺序衔接；多枚棋子同时有几何威胁而全队预算少于潜在攻击次数时，真实应将可兑现性如何计算。这些不等于引擎已有实现或形式化裁判已完整批准。
5. **来源专属例外须保留**：现行刺杀来源的【无形】暂不形成有效将军；飞行棋现行不能【进攻】，故不能因暗影步获得一个几何就取消飞行状态的进攻禁令。双形态来源共存和来源例外仍须项目审查。

### 5. 控制权、空间变化与存活

1. 用户明确同意：资格属于**潜行者方控制下的棋子及对应来源**，不随棋子控制权转移。棋子失去潜行者方控制时既有资格**立即清除**；即使之后重新归潜行者方控制，也不会恢复旧资格，须成功重新前进获得新资格。
2. 用户明确选择 **【移置】后资格保留 A**：只要棋子仍存活、控制权未失去，资格依附于棋子，不依附原坐标；移置后若在资格期限内使用，从**当前位置**向本方底线沿同纵列后退一格；移置不刷新有效期。
3. 资格不得在棋子死亡后凭旧记录自动给其他棋子或复活新实例。具体同身份复活／历史回溯可恢复什么临时资格，须结合来源权威评估，未直接取得用户确认。
4. 用户曾提出「强迫」行动对资格的关系问题，**在用户追问正式来源并要求删除关键词后并未确认那一候选规则**。不能把助手的「强迫动作一定消耗/刷新暗影步」建议伪写成新设计决定；需要时改从「这枚棋子实际完成哪一种【移动】/【进攻】」及具体来源限制重新讨论。

## 三、关键仍未决／不得推定

- 特殊后退与暗棋、将帅照面、同格飞地、河道、【无形】、封锁与免疫、其他特别防御、移置后特殊空间、H10 身份映射、M07 控制翻转或短时操控的全部交叉。
- 同一棋子的下一次行动如果由来源强制限定，是否能选择暗影步；如果没有进行合法【移动】/【进攻】而是专属【降落】、【移置】或占步技能，是否算「该棋下一次行动」：尚未最终裁定；不得由关键词「强迫」是否存在推断。
- 失败扣费已确认一般规则（合法发动即扣）；异常原子回滚、历史回溯恢复、无合法落位、即时自毁等少见来源须按具体适用条件核对，不能自造特例。
