## 1. 当前权威基线（不得由本候选覆盖）

**现行规则正文**：`worklines/standard/rules/shared/02_CURRENT_HEROES.md` → `H02 潜行者｜刺杀`；通用【无形】参照 `worklines/standard/rules/shared/01_CURRENT_RULES.md` §5.1，适用模式还须读取相应专属确认，不以本收束稿替代完整权威源。

原 H02 刺杀机制的关键、已确认部分：

1. 每个【刺杀】来源每局一次；**英雄来源与【暗影之舞】来源独立**，同一时间最多一个刺杀潜行来源。
2. 发动时选择当前合法控制的一枚**己方明置非将/帅棋**；该棋在发动回合完成一次正常合法【移动】或一次**普通【进攻】**。发动回合的进攻**不**提前享有刺杀的特殊致死、绕防御、指定无形权限。
3. 行动正常完成、棋仍存活并由己方控制后，获得该来源【无形】，在**随后两个己方正式回合**内保留一次刺杀机会。若发动当回合普通进攻被战士普通防御拦截并弹回，则发动不成立，来源不消耗。
4. 后续刺杀仍按该棋当时合法的进攻几何，是一次【进攻】；可指定通常不能被直接指定的【无形】终点目标，对终点执行来源专属致死、绕过战士**普通防御**。**不得以将/帅为刺杀目标**；【龙鳞】等明确拦截进攻本体终点击杀的来源仍能拦截。
5. 刺杀来源【无形】保留棋子的空间存在和普通攻击几何，但不产生有效将军；到第二个后续己方正式回合未用时到期，期间该棋选择普通行动却不用刺杀机会则机会随行动结束。
6. `02_CURRENT_HEROES.md` 中 2026-10-17 至 10-19 已确认的 H02＋M04/H21 **限定交互**继续有效。尤其 M04 路径【碾碎】与 H02 终点特殊刺杀是独立来源，不能把终点绕防御外推至路径；具体条件、龙鳞与返回状态按原来源。不得因本次创意讨论改写其确认。
7. 通用【无形】**不是自动视觉消失或穿过棋子**：有【地面】仍占格、阻路径、当炮架/马腿/象眼；通常影响的是能否被**直接指定**。H02 不将军限制是来源特例。

## 3. 本轮用户已经明确的**设计理念**（不等于玩法条款变更）

### 3.1 冷酷形态的核心体验

在“出其不意地消灭敌人”与“无论敌人如何防御都拥有更强的杀伤能力”之间，用户明确选择**前者**：

> “我认为应该是第1种”

其中“第1种”的具体指代是**“出其不意地消灭敌人”**，不是单纯数值压制/绝对破防。

用户进一步表达（摘录原意，保留关键原句）：

> “不论敌人如何防御，都能给予重创，这似乎不是潜行者的风格……所以潜行者不应该有这种特色，他的无视防御击杀的本质其实是偷袭带来的效果。这是不是很有风味？”

**本轮可确认的方向**：潜行者的特殊致死/绕过部分普通防御，叙事本质是**偷袭使普通防御来不及有效发挥作用**，并非角色拥有普遍无敌的蛮力；仍应容许有来源依据的防护与反制。战士巨斧的力量/范围定位作为对比，不因此修改战士技能。

**设计解释 ≠ 规则扩张/削弱**：这里没有批准“无视所有防御”，也没有决定移除现行 H02 绕战士普通防御、无形、目标限制、两回合窗口等任何一条。

### 3.2 与暗影步的区分

- 冷酷刺杀：隐蔽准备 → 寻找关键机会 → 突然、精准地消灭敌棋；机动/生存手段如保留，也应**服务于突袭**。
- 灵动暗影步：移动/回退/持续位置经营与周旋；不让两个形态都以“打完就安全脱身”为唯一卖点。
- **风险**：若暗影步 A 保留击杀结果并回退，而未来又允许与刺杀任意同回合叠加，可能产生过强的击杀后安全逃脱组合。当前**没有批准**该叠加或形态切换规则。

以上是设计定位与风险判断，不是新可执行技能文本。

## 4. 本轮核心讨论：刺杀准备的公开信息

当用户被提供三个**信息机制方向候选**时，表达了：

> “我倾向 H02 刺杀信息方案 C，继续分析和完善，不直接定稿。”

**状态特别说明：C 是用户目前偏好的讨论方向，绝不能登记为“C 已最终确认/已生效”。**

三方向定义：

- **A 候选**：敌方知道哪一枚棋正在准备刺杀，但不知道最终攻击目标；以威慑为主。
- **B 候选**：敌方不知道哪一枚棋正在准备刺杀；以全面隐藏为主。
- **C 候选（用户当前倾向，未定稿）**：**敌方知道潜行者进入刺杀准备状态，但不知道具体由哪枚己方棋充当刺客**。营造“已知危险逼近、未知杀手是谁”的体验，同时寻求合理反制空间。

C 方案此刻只决定**探索的方向**；具体公开时点/界面、内部选定刺客的时点、无形是否保留、代价/时限/发动条件、对手可推断程度均未确认。

## 5. 已识别的两个核心设计漏洞及候选改法

### 5.1 “发动回合必须由所选棋行动”可能导致身份泄露

现行 H02 发动和**所选刺客在当回合完成普通行动**紧密绑定。在每回合通常一次主行动的前提下，若准备状态**公开**，对手可把公开宣告与刚刚行动的棋子对上，几乎直接识别刺客；即使 UI 不显示专门身份标记，也不能称真正隐藏。

**助手提出但用户尚未回答/批准的实质修改候选**：允许在发动准备时**秘密选定一枚合格己方棋子，而不再强制所选棋就是该回合实际行动的棋**，从而降低“准备事件 ↔ 唯一行动棋”的一对一对应。其选择集合、是否还需行动/付费、是否占步、具体时序和强度代价全部未知。这个建议**不是**正式规则，也不能将“用户倾向 C”推断成“用户批准解除行动绑定”。

### 5.2 【无形】的可被直接指定差异可能泄露身份

若秘密刺客的【无形】只作用于那枚棋，敌方可通过直接指定是否合法、行动提示/可选状态，间接反推出谁是刺客；**隐藏 UI 标记不等于有效保密**。

**助手提出但用户尚未批准的候选**：把“身份隐藏”与“通常的无形保护”区分开，甚至探索**准备期间不自动获得可暴露身份的无形保护**，让敌方仍有正常进攻潜在刺客的机会。此项会改变现行生存能力与追击风险，需要同完整候选一起平衡，不能悄然按澄清执行。

**注意**：原【秘密】机制的反侧信道要求存在，但 H02 尚未明确获整套【秘密】标记；不得先假定已保密或自动套用，从而覆盖既有实际公开状态。

## 6. 需下一轮优先讨论而非自行定稿

优先顺序建议：

1. **先审 C 的反推可行性**：公开何种事件/哪个时点？对手看到一次普通行动时能推断什么？在普通、暗子模式与不同合法局面下有多少真实候选？
2. **再审刺客选择与行动绑定**：是否保留原同回合行动条件、改为回合前/后选、改为既定候选池，或采用其他不改变强度的解法？用真实最小棋局反例检查；不急于承诺第5.1节助手建议。
3. **再审准备期状态**：普通【无形】保护、单独“隐匿准备”信息、反制和状态探测，是否存在更少改动且可真正保密的折中。
4. **最后审平衡与交互**：原两回合机会、英雄/暗影之舞来源次数、实际攻击目标与龙鳞/战士/M04、形态切换与暗影步 A/B 的联动。每个方案说明代价、时序、反例和规则差分；正式结果由用户选定。
5. 尤其不能把“无法知道具体刺客”误读成“对手无法从棋盘行为合理推理刺客是谁”；目标应定义为**不由系统直接/侧通道泄露**，而不是禁止任何聪明推断。
