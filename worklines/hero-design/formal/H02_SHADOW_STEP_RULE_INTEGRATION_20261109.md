## 一、形态定位与技能身份

1. 潜行者目前研究**冷酷／刺杀**与**灵动／暗影步**两种形态／职业方向；**不是**在对局中随时任意切换。哪种属于表/里、完整技能包与其他旧技能是否兼容，尚待单独确定。此处只完整定义**灵动形态的暗影步**。
2. 灵动形态的核心体验是**“自己进退自如”**，侧重己方棋子的机动、路线选择与周旋，不以无条件击杀或时间回溯为核心。暗影步是**被动授予临时特殊走法资格**，不是主动将棋子瞬移到历史位置、不是撤销吃子/历史，也**不会自行增加一次行动机会**。
3. 暗影步并非仅赋予兵卒，而是适用于潜行者方当前合法控制、且来源允许行动的**任意己方棋子**；但棋子仍受空间状态、目标、将帅安全与各来源独有禁止条件制约，不能因此突破“该棋不得进攻”等禁令。

## 二、取得资格：成功前进

1. 一枚当前由潜行者方合法控制的棋子，成功完成一次合法【移动】或【进攻】，若**终点相对行号大于起点相对行号**，则该棋在该次行动实际成功完成后立即取得**一次暗影步资格**。
2. **向前**以执行动作的阵营**自身底线**为第 1 行，朝敌方底线方向行号增加；不以屏幕统一上下方向判断。可以直线、斜线或跨越多行，只比较**该次行动的起终点**。同行、后退或仅在中途经过更前方位置而终点未增行，不取得资格。
3. 成功【进攻】与成功【移动】均能触发，不要求杀死目标；动作是否合法、是否真正完成成功前进，须由来源裁判确定。非法请求或尚未成功发生的动作不能提前授予。
4. 【移置】不是【移动】或【进攻】，不能凭单纯位置改变取得资格，也不自动被判为本棋“成功前进”；其他来源若明确改变动作类型，则按真实来源而不是视觉位置推断。
5. **资格授予时点为成功前进行动成立后立即生效**，无需等待下一个己方正式回合；若同一正式回合内来源另行合法给予该棋额外行动机会，允许当回合就选择使用暗影步。
6. 作为被动授予的资格**不会倒过来把那次普通Ⅰ级前进追溯升级为Ⅱ级**。后续真正调用特殊后退几何时，才按下文的Ⅱ级特殊走法判定。

## 三、特殊后退走法及攻击边界

1. 只有**持有有效资格的该枚棋子**，在其下一次符合来源限制的行动机会中，才可选择：**从当前位置，沿同一纵列朝该阵营己方底线方向，恰好后退一格**。不能斜退、不能连续两格、不能以此增加主行动次数。
2. 该后退可作为合法的【移动】（落在来源允许的空位），也可作为合法【进攻】（落到来源允许的敌方目标）；动作类型及目标是否合法分别判断，不能因存在走法资格把本来不允许的目标或行动类型强行放行。
3. **独立进攻几何**：特殊暗影步【进攻】不需要满足棋子兵种原本的攻击路线/距离/炮架几何。例如持资格的炮可以不依靠炮架，直接向后攻击相邻一格合法敌棋。这是额外的一格后退进攻走法，不只是将原棋种攻击方向反转。
4. 特殊几何**不自动绕过**普通防御、战士铁甲、龙鳞、免疫、封锁、棋子目标限制、路径/落位、暗棋揭示和隐藏权限、己方将帅安全及其他独立来源的禁令；不能借暗影步获得刺杀形态的专属指定【无形】或破防权限。
5. **不得直接以将／帅为【进攻】吃子目标**；但该后退几何按后文条件可以作为合法威胁参与【将军】评估。“可以产生将军”与“允许直接吃掉将帅”是两回事。
6. 来源专属例外仍有效：H02 旧**刺杀来源的【无形】状态不形成有效将军**，不能以暗影步几何抹掉该限制；现行**飞行棋不得【进攻】**，持有暗影步资格也不能借走法几何绕开这一禁令。对于【地面】/飞行同格、河道、暗棋、将帅照面等尚需具体模式裁判处理的条件，不自增豁免。
7. **普通合法后退免费**：如果一枚棋本来就可按其正常有效规则沿当前纵列后退一格执行相同动作类型，则该动作按普通走法执行、**不扣全队三次特殊额度**，不自动变成Ⅱ级、也不凭此获得额外行动；该棋的“下一次行动”资格是否保留，依下一节实际动作消耗/刷新规则执行。

## 四、资格有效期、消耗、刷新与并存

1. **获得即有效**，最长持续到**潜行者方下一正式回合结束**；若届时未使用，资格到期清除。这里“下一”是指取得资格后下一次正常属于潜行者方的正式回合，不要求紧接同一正式回合再次行动。
2. 资格限定于**取得资格的那枚棋子自己的下一次有效【移动】或【进攻】行动**，不是阵营的下一次行动。其他友棋的行动、来源自动触发或只是切换/经过其他正式回合，不能独自消耗这枚棋子的资格；仍受时间上限限制。
3. 该棋下一次合法行动若使用特殊后退，随本次使用消耗该棋已有资格；若选择一次普通合法【移动】或【进攻】而不使用特殊走法，旧资格也随其下一次行动消耗。**普通合法后退虽然免费，却不会因此把旧资格保留到下下次本棋行动。**
4. 若该棋**下一次行动再一次成功前进**：先消耗旧资格，再立即获得新的**一次**资格并刷新有效期至该次新前进后的下一己方正式回合末；不能叠加两份资格，也不因先前任一回合曾前进过而长期持有旧资格。
5. 若该棋下一次行动没有成功前进，旧资格结束，不重新取得资格。失败/拦截等边界以该动作是否被来源认可为“已合法发动”“成功前进”分别判断，不能把未发生的成功位移登记为新资格。
6. **同一方多枚不同棋子**可以通过各自合法前进行动同时持有各自一份资格，彼此不消耗/覆盖；这不增加全队三次额度，也不增加任何人的普通行动次数。
7. 不把通用【移置】、独立【降落】、占步技能及其他并非【移动】/【进攻】的专属动作，未经来源审查就算作“该棋下次行动”；非正常主动/强制效果的资格消耗以其真实动作和来源权限确定，相关特殊交叉仍有未决。

## 五、特殊额度、合法发起与防御拦截

1. **全队共享 3 次/局**，对象为确实调用了本技能**特殊后退几何**的【移动】或【进攻】，不是每枚棋三次；不会因多棋并存资格而增加。
2. **合法发动特殊走法即扣 1 次**，不以最终吃子成功与否决定费用。即使该后退【进攻】被战士普通防御或龙鳞拦截、攻击者弹回、目标仍存活、未达预想结果，已经合法使用的特殊额度**不返还**，行动机会按原来源消耗。
3. **非法请求/尚未被接受的发动不扣费**；按钮点击、探测、动作预览均不等于合法消耗。超出合法目标、王安全或其它来源限制的尝试不能先扣额。
4. 如该棋本来就可以通过**普通合法走法**完成相同后退动作，则**免费、不触发该特殊额度扣费**；若全队 3 次已用尽仍保留普通走法本身，不因此多出新战斗收益。
5. 该技能不自行补充特殊次数，也不提供行动机会；由其他英雄/效果提供的行动机会另按第六节的等级、类型及来源限制审查。

## 六、行动来源、Ⅰ/Ⅱ/Ⅲ等级与【额外】行动

1. 现行三级体系：**Ⅰ级俗手**为长期普通主行动；**Ⅱ级本手**为调用英雄/畸变特殊走法、有限资源或特定技能结算的棋盘行动；**Ⅲ级妙手**为改写控制、时间线或回合/行动结构。动作类型【移动】/【进攻】与等级为**不同维度**。
2. **暗影步特殊后退几何归Ⅱ级本手**；即使外观上只退一格，也不是Ⅰ级普通行动。原本就合法的一格普通后退仍按其自身合法级别判定。
3. 其他来源合法授予棋子一次【额外】【移动】或【进攻】时，**原则上可以使用已经获得的暗影步特殊几何**，除非该额外行动来源限制了允许的走法等级或动作类别。若仅允许Ⅰ级，就不得使用Ⅱ级特殊后退；若只允许【移动】，不能借暗影步进行【进攻】。
4. 即使因此**取得资格后在同一正式回合立即使用**，也不额外开一个正式回合；额外行动的数量、时点、可选/必选及本棋能否行动以来源规定为准。不能把 H02 被动变成自动获得一次额外走棋。
5. 实际触发资格的行动仍按**棋子所属原阵营及来源**判断。临时由别人选择走法，不天然改变技能归属；但若本棋**实际控制权归属发生变化**，资格仍依下一节清除。

## 七、控制权、位置变化、死亡与历史快照

1. 暗影步资格仅属于当前**潜行者方合法控制的特定棋子**；发生实际失去潜行者方控制权时，已有资格**立即清除**，不会随棋倒戈，后来夺回不恢复旧资格，必须再次成功前进取得。临时**选择权**变化与棋子真实**归属/控制权**变化不能混淆。
2. 普通【移置】只改变当前位置。棋仍存活、潜行者方控制未变且资格未到期时，**资格保留、不刷新有效期**；若之后合法使用特殊后退，从**移置后的当前格**判断同纵列后退一格。正常【移置】不取得资格。
3. 棋子死亡/被【消灭】不允许把资格转赠其他棋；通常不自动因一个后续新棋/新生实例恢复既有资格。**明确的历史完整快照【回溯】**属于来源例外：可按快照真实恢复该棋当时持有的资格和旧期限，不能机械一律清零，也不能凭已取消的历史后续前进保留新资格。
4. 复活后的同身份资格、暂时控制/暗置/飞行等特殊源若未给出确切历史恢复语义，须结合实际来源进行专项裁判审查；不能把 H05 整回合快照规则自动推广给所有复活与【移置】技能。

## 八、H05【扭曲时间线】的已确认最终交互

1. H05 的新机制是**重演对手紧接上一正式回合**，恢复到该回合**开始结算前的完整权威快照**，不是只把某枚棋【移置】回以前的格子。对手的旧回合必须恰好主动执行过**一次合法Ⅰ级**【移动】或【进攻】、没有其他主动Ⅰ或Ⅱ/Ⅲ行为；H05 的发动许可、完整重演与失败退款按 `H05_TWISTED_TIMELINE_RULE_CONSOLIDATED_20261111.md` 的已确认正式英雄文本。
2. **时间线快照恢复**：原历史中那次前进赋予的暗影步资格随旧时间线撤销，快照里原本已合法存在的资格依快照恢复；原阵营随后在新时间线重演开始自动结算、必要来源操作、最终回合末结算。
3. H05 只**代为选择原敌方棋子的一次合法Ⅰ级行动**；行动在规则上**仍归潜行者方及其被改写的原正式回合**。如果在新时间线这一枚潜行者棋合法向前【移动】或【进攻】，**正常获得/刷新暗影步资格**。旧“被 H05 操控绝不触发暗影步”以及“回退一律清零”是被明确取代的临时解释，不得复活。
4. H05 被授权改写的主行动必须是Ⅰ级，故**不能直接用Ⅱ级特殊暗影步走法作为这次被控制的唯一Ⅰ级行动**；但允许普通Ⅰ级前进通过潜行者的被动获得资格。
5. 若新时间线被动/来源给潜行者方合法额外行动，该行动**不交给 H05 继续选**；可选由原阵营玩家决定、强制按来源执行，若动作来源允许Ⅱ级及该动作种类，则**可以使用已取得的暗影步**。需要操作时依 H05 来源暂停其计时并开放原阵营独立窗口，不自动创建新的正式回合。
6. H05 新历史随机、隐藏信息、现存倒戈棋不合格、重演前置倒戈导致无法操控、合法与不利结果区别、双方将帅安全、操控前终局失败/操控后终局成立、H05 自己 begin 前专属窗口、成功跳过自己 begin/end、失败本回合不得再试以及独立裁判历史等，以 H05 11-11 整合正式设计全文（含 11-13 增补 §11—§17）为准；这些**不是 H02 暗影步单独新增的例外**。

## 九、特殊将军与重要来源例外

1. **用户已确认：有效暗影步特殊后退【进攻】几何可构成条件性将军威胁**；【将军】是合法威胁判断，不是现实已执行一次【进攻】，不会因此直接对将／帅执行吃子。
2. 该威胁是否成立须检查：特定棋子当时有未过期的资格；当前来源允许其进攻；合法特殊走法有足够剩余额度（否则只能依普通合法几何）；当前目标/空间、防护、禁止条件、双方将帅安全均合法；没有来自刺杀【无形】或飞行不得进攻等来源的独立排除。
3. 获得资格、普通下次行动消耗资格、失去控制、有效期终止、额度使用后等都可能改变条件性威胁，须在适用合法行动原子闭合与正式裁判采样点动态核验；**不能将“前进立刻取得资格”误写成必须再等下一己方回合才可能有威胁**。
4. 同一正式回合若有来源合法的额外行动，可能立即尝试特殊后退；行动中的临时将军不自动变成一次独立的对手应将机会，正式将军/终局仍按**合法原子闭合、来源要求的行动链及真实最终稳定局面**判定，不能靠后续额外动作修补此前源非法的己将危险。
5. **仍待专项裁判核验**：多枚棋各自具资格但共享三次额度、尤其剩余次数小于潜在将军路线数量时，威胁能否兑现及应将排除条件；暗身份揭示、将帅照面、河道、同格飞行/地面、封锁/免疫、H10 映射、M07 控制转移、异常原子回滚及复活的具体测试。它们是未决边界，**不得写成已测试或已经有统一可执行裁判算法**。
6. 与来源明定的终局相接时遵守“**候选终局 → 已承诺原子闭合 → 正式【终结】**”，正式终结后不得产生下一回合、无关技能或额外行动；已有来源特殊终局权限不由暗影步新增。

## 十、区分已确认、历史否决与未定稿对象

### 已确认暗影步技能（本文件单独可读）
- 被动触发为一枚己控棋**成功向前【移动】或【进攻】**，按各自底线相对行号计算；【移置】不触发。
- **立即**获得本棋下一次行动的同纵列**直线后退恰好一格**【移动】或独立几何【进攻】资格；不赠送一次行动；最迟下一己方正式回合末失效。
- 本棋下次行动消耗资格，再次成功前进可**刷新但不叠加**；多枚棋可并存。
