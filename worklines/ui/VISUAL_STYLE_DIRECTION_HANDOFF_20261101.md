## 2. 视觉风格：已明确的审美要求
1. 对旧淡黄色／米黄色仿古纸卷基底不再满意，希望探索黑白水墨的新视觉方向；不是只有一张纯白纸的极简空白。
2. 用户尤其认可其提供的**骑马冲锋等参考图上半部**：有冲击力的水墨线条、甩动与喷溅的墨迹、鲜明方向感、力量、速度、锋利、帅气；明确拒绝软绵绵的水墨表现。
3. 整体基本色：黑、白、灰的现代新水墨、武侠视觉。**人物采用“写实脸部／结构 + 写意水墨笔触与衣袍”混合型（人物风格选项 C）**。
4. 颜色使用：用户对第一轮颜色选择选**C（界面以黑白为主，英雄和技能允许更丰富的彩色）**；对后续具体范围选**B（重要按钮和状态也可少量彩色）**。二者合并理解为灰阶为基础、英雄/技能允许更明显的强调色、重点功能状态可以克制使用彩色；不得将全 UI 泛彩色视为已获授权。
5. 棋盘视觉：选择**A 为主**——希望棋盘也有较强视觉冲击，同时**必须保持清晰、锋利、可辨认**；不可把助手曾建议的“低干扰 B”为用户选择。
6. 冷峻肃杀、飘逸侠气、神秘诡谲三类**整体气质的主次尚未选定**。用户表示无法凭文字判断实际效果，宜由主线安排在相同角色/场景约束下的三种对比视觉样本，再由用户决定；不能把 AI 的偏好 A+B 伪装成用户已定。

## 3. 人物服装：已暂定的一项元素（非全角色制服）
重点是用户对**第一张六款围领方案板中的 A（不是后来第二张板的 A′）**的真实纯布料材质和自然包裹感表示满意；用户多次澄清必须引用**第一版 A 的材质语言**，结构需独立修改。逐轮明确选择如下：
- **材料**：现实可穿的纯布料、中等厚度；自然重量、层叠褶皱与真实布面张力；不用硬质护甲领或华而不实的幻想材料。
- **颈部**：适度收束，降低高围脖的厚堆叠，避免遮脸和臃肿。
- **长度**：用户选择“2”，向下覆盖**胸口上半部**。
- **包裹方式**：选择“C”，自然交错而非过分对称或夸张偏披。
- **连接**：选择“B”，与肩部/衣襟**半连接**，既可看见布料交叠，又与上衣整体融为一体；非独立围巾。
- **厚薄**：选择“B”，**中等厚度**。
- **效果图**：助手按上述约束生成过服装多角度设计图；用户回复“可以，看着还不错，先这么暂定了”，属于**该单项服装方案的暂定认可**，不是该图作为游戏正式角色/界面的视觉审批；该生成图目前不在 GitHub 本记录中。
- 武侠元素中，武器、发型、披风等仍需后续挑选，未在本轮一并定稿。

## 4. 自然／环境：当前阶段确认使用，长期可扩展
先前 AI 自选的竹林、瀑布、云雾、亭阁、泛山水等**不构成用户确认**，不得作为已选清单。

用户后来自行明确希望：**雪山、雪、风、梅花树、远离人烟的野外建筑（可能废弃）**；对建筑候选选**A：荒野客栈、废弃驿站**，并明确“保留”梅花**红色**（红梅、黑枝、积雪和风雪可形成黑白中的强色彩对比）。

阶段策略用户明确：**长期采用“允许多季节/多环境”的开放世界场景体系（方案二），但现在资源有限，只实施“冬季风雪主题”（方案一）**。现阶段不要分散成本去做其他季节场景；结构设计要考虑将来替换和拓展，不把雪永久写成游戏世界观唯一季节。雪山、风雪、红梅、荒野客栈／废弃驿站是当前可用的主题资源，不要求每屏同时出现。
