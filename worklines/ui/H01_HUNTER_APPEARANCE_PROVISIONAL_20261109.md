## 1. 人物轮廓｜逐项确认并整体升级

| 元素 | 暂时确认规格 |
|---|---|
| 身份 | **山野游猎者**，来自**现代文明发展前的一个世界**；不强绑定现实某个民族、国家或武侠流派 |
| 年龄气质 | **成熟猎手型**，视觉约三十岁上下，不将数字年龄锁死 |
| 体型 | **高大厚实的壮汉型**，介于「结实强健」与「高大魁梧」之间，但用户明确选**肩腰差距较小、整体厚实**，不是宽肩窄腰健美倒三角；肩背、胸部、腰腹厚实，强壮而保留敏捷性 |
| 面容 | **风霜硬朗型**，轮廓坚毅、眼神敏锐；不得误改成混合「沉静俊逸型」 |
| 神情 | **沉稳警觉＋冷峻威严（A+B 融合）**；威严来自经验、力量和专注，而非暴怒咆哮 |
| 胡须 | **明显短胡须**，集中于嘴周、下颌，修整自然，不浓密遮挡轮廓 |
| 旧伤 | **多处细小、已愈合旧伤**；眉角、面颊、下颌等只是合理放置候选，不固定为必须同位置 |
| 头发 | **中长发＋后颈低位束发**，少许散发，不是现代精细短发；用户给出的生活逻辑是前现代自行用刀修发时留一定长度、日常束起 |

用户对发型的原始理由「短发不易剃成，如果猎人使用刀来处理头发，反而要有一些长度」，作为该角色的设计动机，不上升为所有前现代文化的通用历史断言。

## 2. 服装、材料和气候适应

1. **主色**：深棕＋土褐色，强调自然布、皮革、山林生存；不强制黑白水墨。毛皮为**灰褐色**。
2. **连帽短斗篷**：用户选**B 连帽短斗篷**及长度**B 中背型**；兜帽与短斗篷相连，覆盖头肩至背部中段。前现代材料与工艺，外层可选厚布、油蜡处理织物或皮革，以改善挡雨防风；内层使用毛皮或羊毛保暖，帽缘／肩颈少量灰褐毛皮外露。**防泼水并非完全防水**，不使用现代冲锋衣视觉；不采用完整兽首头冠作为默认。
3. **躯干**：**B 皮革强化猎装**。厚实粗纺布/织物为底，胸腹、肩臂等局部皮革补强，强调树枝刮擦防护、耐磨、保暖而非重板甲；这些**不代表游戏中的防御点数或护甲技能**。
4. **护肩**：**B 局部外露皮革护肩**，与毛皮、斗篷自然融合，不做巨大金属甲；先前建议右侧略明显、左侧保留拉弓空间，属于**后续可核的具体构图建议，不单独锁死左右差异**。
5. **左前臂**：选**A 单侧强化皮革护臂**，左手持弓可防弦擦伤；右臂相对轻便。
6. **右手**：选**A 三指皮革护指**，保护食、中、无名指拉弦接触面，不妨碍使用陷阱小工具。
7. **裤装**：**A 修身耐磨猎裤**，厚实织物，膝部局部皮革补强，裤脚收束。
8. **腿足**：**A 传统皮靴＋绑腿**，前现代短/中筒皮靴及可拆换绑腿，侧重耐磨、防刮与维修便利。
9. **整体旧化**：**保养良好，但有比较明显的使用痕迹**；弓、皮革、布料、靴、包袋可出现磨损、褶皱、压痕、旧划伤，仍然整洁、结构可靠，绝非崭新展品或破败流浪装。

## 3. 武器、陷阱与真实挂载视觉

| 元素 | 暂时确认规格 |
|---|---|
| 持弓习惯 | **左手持弓、右手拉弦**（A） |
| 主武器 | **C 中等长度反曲猎弓**；再选定**B 木角复合猎弓**（木材、角材、筋材的前现代工艺）；品质选**B 精良实用型**，维护良好而有长期磨耗；不做魔法名弓、夸张兽骨装饰 |
| 箭囊 | **B 髋侧箭囊**，**右髋偏后**，照顾右手取箭且与斗篷错开；未确认具体箭枝总数 |
| 腰部结构 | **B 主腰带＋辅助斜挂带**，为箭囊、工具袋和猎刀分配重量，避免无序叠挂 |
| 陷阱携带 | **C 混合型**：预制小型机关＋利用环境现场制作；用绳索、小型机关组件、便携工具袋、短钉/木桩等体现，不采用巨大捕兽夹当常规背负物。物件外观是视觉表达，不扩充玩法陷阱的类型、资源或触发机制 |
| 工具布置 | 左腰、腰后可有陷阱工具包；**副武器 A 短猎刀**偏实用（割绳、处理猎物、削木、近身自卫），左腰前侧／左侧**为建议位置**，具体挂位若影响其他装备可调整 |
| 主色与用料 | 工艺耐用，以深棕、土褐猎装为主，灰褐毛皮内衬与少量自然皮革、骨色细节组成层次 |

**装备协调要点**：中背连帽斗篷不应遮死取箭路径；肩部、腰挂和斜带布局不能妨碍拉弓、移动、攀爬。以可用性和辨识度优先，不要求为工业真实防水性能提供未经确认的保证。

## 4. 饰物与状态表现

- **装饰等级：B 少量个人饰物**。用户随后明确指定**兽牙与骨饰为主**，可以用小皮绳、编绳连接；这是角色元素，不自动赋予魔法/宗教设定。
- **布局：B 头肩与颈部为主，少量 C 腰部与工具区辅助**。在帽缘、颈侧、肩部连接处少量点缀；腰带、工具包或刀鞘附近可有小配饰。**不悬挂大量战利品，不变成骨甲/祭司装**。
- 所有装备表现**保养良好但有明显使用痕迹**；旧化强度为已经确认的状态，不改成破旧泥泞或崭新。
- 角色是山野游猎者，而不是套了猎装的现代特种兵、贵族弓手、重甲战士或兽首蛮战士。

## 5. 立绘动作（姿态已选，成图未批）

- **面部神情：A+B**，沉稳警觉且冷峻威严。
- **站姿：B 猎物锁定型**：身体轻微前倾、双脚扎稳、视线锁定远方，左手持弓，右手靠近箭囊准备取箭；不是已经拉弓至满弦的姿态。
- **体态要求**：高大、宽厚、扎实，有狩猎前静止蓄势的紧张感；不做夸张胜利摆拍、暴怒吼叫。
- **构图尚未独立确认**：镜头角度、全身/半身最终版式、图像媒介和角色专属美术风格、背景是否出现以及具体光照属于未来出图参数；当前的「全身角色立绘」是此前尝试的执行范围，**不代表已经审批具体画作**。

## 6. 出图用规格摘要（文字，不包含任何图片）

> 一名来自前现代世界的高大厚实山野猎人，约三十岁，肩胸腰腹均强健、肩腰差距较小。风霜硬朗面容、明显短胡须、多处细小旧伤，中长发在后颈低位束起。神情沉稳警觉且冷峻威严，身体略前倾，左手持精良实用的中等长度木角复合反曲猎弓，右手靠近右髋偏后的箭囊。深棕／土褐色厚布与局部皮革强化猎装，灰褐毛皮内衬的前现代连帽中背型短斗篷，局部外露皮革护肩，左前臂强化护臂、右手三指皮革护指，修身耐磨猎裤、绑腿与传统皮靴。主腰带加辅助斜挂带，左腰和腰后有混合型陷阱工具袋，配一把实用短猎刀；头肩颈部仅少量兽牙、骨饰，腰部小量呼应。装备保养良好、明显使用痕迹。避免现代户外装备、重甲、完整兽首帽、魔法化、华丽战利品堆砌、健美倒三角和破烂流浪汉风。角色绘画媒介与背景可分开设计，不擅自强制水墨或摄影写实。

该摘要是对已确认视觉元素的语义压缩，**不是独立的新版审批或新增属性**。
