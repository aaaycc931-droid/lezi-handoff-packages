## 4. 技术限制：已知与未知严格分开
- GitHub 本身支持存储符合其平台限制的普通 PNG；当前已验证本仓库有文本 GitHub 提交能力，仓库 `lezi-handoff-packages` 为**公开仓库**。
- 连接器公开的 `create_blob` 操作可以接收文本或 `base64` 字符串写入 Git Blob。然而当前会话提供的文件类工具、容器与 GitHub 连接器之间**尚未实际验证可靠、无需模型回显整张图片 Base64 的二进制直传桥梁**。所以只能确定**本轮 PNG 未上传**，不能草率断言“完全不能上传”或“只要变成 Base64 就能安全可控地上传”。
- 根因是否包括连接器文件传输能力、调用路径设计、授权/公开范围、流程中的“未完成仍收束”状态判定，**均需基于真实最小验证确定**。不能绕过平台审核，也不能将工具阻断重写成用户未授权。
