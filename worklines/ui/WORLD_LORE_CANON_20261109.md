## 1. 作者层的绝对起源（剧中不可知）
在遥远到难以衡量的存在的意识中，仅有**「象棋」这个词语一闪而过**。他**没有迷上象棋，没有认真产生念头，没有策划比赛，也没有任何创造世界的意愿或行为**。仅这一个微不足道的意识片段，便使一批多元宇宙发生时空扭曲；若干原本不同世界的时空在扭曲中心交织，诞生一个**崭新的平行世界**。这个新世界就是《乐子象棋》的世界背景；时空扭曲象棋大赛、赛事规则、胜者可获的「时空之力」，以及赛事规则的神秘具象化存在，都伴随世界**自然诞生**，没有被那位存在主动委托或指派。

- 他从未注意到这个世界，从不知道自己创造过它，对它没有兴趣，也从不出现、观察、指导或干涉。
- 世界对他而言“不过是茫茫大海中的一滴水”：这是一种尺度上的比喻，不是世界内生物能够查到的情报。
- **没有任何世界内存在能够窥探他与这个世界之间的联系**，包括乐子本人；不留预言、启示、可追溯的证据或最终可揭开的谜底。这不是他刻意隐藏，而是根本不可接触、不可知。
- 这项作者层真相不应被变成最终反派、最终裁判、可被追寻的幕后神或会登场的角色。
- 早期讨论借用“多拉姆”，后来用户澄清指的是漫威「多玛姆」作为能力想象来源；但**没有确认把漫威多玛姆直接作为本作品的正式人物／官方漫威设定**。现行最高层存在不设世界内可知的名字，均称“至高存在／至高造物”（作者层措辞）。
- **已废止的早期表述**：“至高存在喜欢象棋／主动举办比赛／主动创造宇宙／给参赛者发奖励”；“产生了一个明确的创造念头”。不能再引用这些作为现行正史。

## 2. 新生世界的本体、年代与地理
1. 来源：目前已确认至少**四个彼此不同的英雄来源世界 A、B、C、D**，它们不是红黑棋局阵营，不是同一地理版图里的四个国家，代号暂用；未来是否拓展世界数未定。
2. 世界 A 以魔兽／炉石传说中的世界与角色为**独立致敬参考**，并非作品直接等于艾泽拉斯正史。世界 B、C、D 的具体文明与正式命名尚未确定。
3. 多元宇宙扭曲交织的结果是**新的平行世界**，既不是所有来源世界整体简单迁移，也不是原本某一世界的更名；其内部已有相对独立的生活与历史。
4. **世界诞生仅数年**，却已完成一定程度的探索与初步秩序建立。
5. 地域构成采用**相对完整的来源地域 + 局部破碎拼接地带并存**。主流交界以局部交叠为主、少数特殊地区深度交融。时空扭曲中心附近可能尤其复杂；不将“可能”写成已确定位置和物理机制。
6. 城市、森林、山脉、既存居民、组织和文化可能随地域延续，因此数年内可有秩序和交通；远非每个地方都混乱，也不是所有地貌长期破碎。
7. 视觉层面：背景已确认「飘逸侠气」的探索方向，但英雄的文化、服饰、材质与绘画表达**独立于背景**，不强制所有英雄是武侠水墨风。旧批准画面不因世界观新增而自动更改。

## 3. 时空扭曲的现状
1. 扭曲**仍在持续**，但世界主体可相对稳定、生活与贸易正常展开；并非整体随时崩塌。
2. 危险度为**局部高危险度**：危险交界和高危扭曲区可出现空间错位、道路中断、地貌改变、新碎片相接等可能现象；具体异常清单和强度还未完成逐项定稿。
3. 目前时空扭曲**基本不可预测**；没有稳定、可靠的规律或预测体系，强大魔法和技术也不被自动视作能够控制它。研究、记录、规避危险仍然可以进行；不代表绝对禁止所有个别时间能力。
4. 新世界与部分原世界**偶发性连通**，通道难预测、不稳定、可能不一定双向，无法作为常规交通运输；并非已形成稳定往来体系。原世界具体保留、损坏或延续到什么程度，尚未确定。
5. 社会对异常的总体应对是**防御与探索并行**：保护稳定居住区，也由探索队、学者、冒险者进入未知地带。各势力可有差异，保守隔离和激进争夺不被禁绝。

## 4. 社会、权力和语言
1. 原有文明组织与**新兴跨世界组织并存**：部分旧王国、军队、宗教／政治组织留有结构；贸易镇、探索团体、合作组织等逐渐出现。
2. **多个政治中心并存**，没有统一的世界政府；不同地区的自治、贸易、摩擦、联盟和冲突仍可存在。
3. 世界诞生仅数年，初步秩序分布不均；部分边缘与未知地带尚未建立稳定管理。
4. **语言机制采用混合型 C**：不同文明仍保留原语言；有些可以直接交流，其他需要学习、翻译者或部分文明已有的翻译魔法。不存在默认的全宇宙同语。
5. 世界内生命可以探索时空现象、对宇宙起源提出理论，但**永远无法知道第1节的真实起源**，这条创作边界高于普通调查剧情的开放性。

## 5. 时空扭曲象棋大赛｜自然诞生的赛事
1. 这不是普通象棋，而是**「时空扭曲象棋大赛」**。比赛是一种与新世界一同出现的特殊现实／超自然赛事体系。
2. 赛事、规则和最终奖励**随世界自然出现**；至高存在不担任主办者或裁判。
3. **胜者可获得「时空之力」**，但其可支配范围、确切形式、授予时机、是否存在多届赛事等均未决定；不得自行将“时空之力”升级为“无所不能”。
4. **强大的存在会被选中获得参赛资格**；被选中者有权**接受或放弃**，资格不是强制参赛命令。
5. 愿意参赛者被传送至**「被选中者空间」**，在其中进行对战。选中条件的客观指标、邀请形式、空间结构与回返机制尚待设计。
6. 棋局采用**指挥者模式 A**：参赛者指挥棋子，并以自己的英雄能力影响棋局；不是把参赛者本人默认变成棋盘棋子。这是世界观解释，**不修改已存在的游戏技能、裁判、回合与代码**。

## 6. 「乐子」｜规则的具象化和赛事主持者
**名字「乐子」是他自己取的。**他认为“乐子”代表快乐和有趣；他喜欢象棋，也喜欢有趣、快乐的事物。

### 他的本质与能力
- 他伴随新世界的比赛规则**自然诞生**，是相关**根本规则的具象化个体**，不是被至高存在有意创造、任命或派遣的仆从。
- 他不知道自己为什么诞生，也不知道规则为什么存在，更不知道至高存在与世界的关系；对世界起源没有特权知识。
- 他已经拥有**真实、独立的自我意识、情感、偏好与人格**，并非只会机械执行指令。
- 拥有极其强大的力量，按用户设想，**甚至有能力创造宇宙**。不得把“必须遵循根本规则”误解为他力量不够强。
- 他**必须执行构成自身存在的根本规则**，但在不违背根本规则时可决定具体执行方法、与棋手交流、展现个人兴趣和组织方式。
- **根本职责范围采用 B**：维持赛事运行与世界存在／根本秩序，防止足以毁坏赛事体系或世界基本秩序的事件；不意味着必须治理每个国家、扑灭一切战争或指挥所有文明。
- 性格采用**自由多变型 C**：可以顽皮活泼、幽默随性，也可以优雅从容甚至庄重严肃；表现随自己的心情与兴趣变化。不可写成单一刻板人格。
- 他爱好象棋是个人性格，**举办比赛是本体职责**；不能倒置为“因为爱好象棋才产生规则”，也不能把至高存在与乐子混为同一个人物。

### 两个层级的反差
- **至高存在**：没有意愿，仅有一个“象棋”词语的意识闪现，便无意识地创造了现实；永不登场、永不知晓此世界。
- **乐子**：真切拥有意愿和人格，喜爱象棋，能力甚至可创造宇宙；但作为世界内规则化身，必须维持其根本规则。
- 这两个存在的层级与认知不可混同。**乐子不是至高存在的分身、使者或已知造物计划的一环**。
