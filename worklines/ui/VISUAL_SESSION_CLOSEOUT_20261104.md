## 5. 新形成的长期 UI 协作方法（已获得用户明确肯定）
- 用户表达：很难用语言精确讲清五官与笔法，“你可以按不同的方向生成，然后我来看效果……这作为我们的项目推进的一种规则让我来选吗”；随后对依选中方案再分支的工作方式说「我们就这么做，这样就比较好」。
- **固定流程：定义母版/允许修改处 → 给 3—4 个针对单变量有差异的 A/B/C/D 视觉候选供用户看图选择（必要时其他数量）→ 用户选择、排除、融合或反馈 → 锁定喜欢的版本作为下一轮基准 → 沿此版再生成少量新方向，逐层收敛 → 执行视觉与像素保真检查 → 只有用户具体审批才能提升身份。**
- 用户不用理解“水墨笔法”的专业术语，AI 不得因用户没有说清就猜成形式主义的变更；优先通过可比视觉实例澄清，不能把 AI 的推荐写成用户确认。
- 一次多个方案是 **探索比选**，不等于改变 UI 正式“单张候选具体审批”规则；对局部精修必须固定原图、真实蒙版、保护区外0差分。失控改全图立即拒绝使用。
- 规则已同步到固定 `UI_WORK_AGREEMENT.md` 与 `UI_FIDELITY_POLICY.md` 末段；不触碰通用协作正文唯一作者源、不同项目的规范或 UI 正式批准指针。
