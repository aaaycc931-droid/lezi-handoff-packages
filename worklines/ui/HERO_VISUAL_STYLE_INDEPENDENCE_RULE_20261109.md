# 《乐子象棋》英雄视觉设计规则：角色风格与游戏背景画风独立

- 规则 ID：UI-HERO-VISUAL-INDEPENDENCE-20261109-01
- 确认日期：2026-11-09（当前 UI 独立视觉设计对话）
- 适用范围：本独立 UI 视觉工作线的全部英雄角色造型与视觉设计；不直接修改玩法、项目主线或通用协作规则
- 状态：**用户明确确认的支线级设计规则，当前支线后续设计应执行**；项目主线接收、正式 UI 总规范采用和游戏实现尚未核验
- 生效来源：用户当轮原话「角色的设定与游戏风格设定不同，游戏背景画风是侠气，角色单独独立出风格，不与游戏强绑定」；经助手复述角色身份、文化、服饰、体貌和绘画表现可独立探索后，用户答「是的」；随后明确要求「刚刚这个改动十分重要，升级为规则内容」。
- 变更类型：**modification / scope correction**。纠正此前助手把游戏背景水墨侠气等同于每名英雄的强制人物画风的误用；不是撤销已批准的环境背景风格。

## 1. 规则正文（持续有效）

1. **独立风格原则**：游戏的背景／场景视觉方向与每位英雄自身的角色风格是两个不同层级。背景当前选定的「飘逸侠气」水墨语言，不自动成为所有英雄造型、文化背景、服装、武器或艺术表现技法的强制模板。
2. **角色自主定义**：每名英雄可依据其身份定位、能力特色与用户审美判断，分别确定年龄气质、面容体态、发型、服饰装备、文化来源、配色和独立的绘画表现形式。不同英雄之间不要求同一种武侠人物造型或相同绘画媒介。
3. **禁止擅自强绑定**：不得在用户尚未逐角色选择时，把黑白水墨、冷白皮肤、飘逸衣袍、武侠服装、风雪红梅等**场景／既有风格参考条件**自动施加于英雄人物自身；亦不得为了匹配背景而替用户修改已确认的角色设计。
4. **背景继续有效**：本规则不否定背景／环境层已经确认的「飘逸侠气」、强对比水墨和现阶段雪山风雪红梅等视觉方向；不自动撤销此前 UI 静态审批或背景设计。
5. **视觉融合≠角色统一**：未来合成角色与场景时，允许讨论清晰度、光影、色彩对比、层级、比例和界面可读性等必要的表现协调；协调方案不得默认为改变角色风格，影响用户审美决定的改动需先呈现候选并获确认。
6. **角色先行**：优先完成各英雄的可见形象设定（面容、体态、发型、服饰、装备、独特标志），再依据已确认设定制作角色候选图。无需为纯外观任务先敲定角色传记、成长历程或与 UI 无关的世界观细节。
7. **审批逐对象**：某画风参考被确认，不等于人物身份、服装、武器、整体角色外观或全部英雄画风被确认；每个角色的具体外观和成图仍须按对象获得用户确认。
