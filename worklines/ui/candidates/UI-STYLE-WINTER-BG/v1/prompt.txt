Use case: stylized-concept
Asset type: 一张《乐子象棋》新画风的竖版游戏 UI 背景风格探索图，独立待审样图。
Primary request: 延续所附已选参考原图的绘画语言，创作一幅全新的冬季雪山红梅与荒野驿站背景；仅一幅连续完整画面，9:16竖向。
Input image: 附图是已获认可的三人联合水墨“画风参考”，不是编辑目标；仅提取背景山石、长锋飞白、黑灰大墨带、清冷纸白与有限梅红的画法。不要复制参考中的人物，不要三联、分栏、拼图。
Scene/backdrop: 清冷明亮的冬日山野，雪岭层层远去；一处小型荒野驿站或客栈安静伏在山坡，屋顶覆雪；近景以弯曲的梅枝与有力度的黑色山石笔势引导视线，少量朱红梅花和零星花瓣；轻雪与山风由流畅白色空隙和细长风势表现。
Style/medium: 黑白灰中国新水墨，飘逸侠气、干净克制但黑白反差鲜明。长而连贯、富有韧性的扫笔和大片有方向的深墨/灰墨块组织山石与风势，边缘干笔飞白清晰；减少随机散点和喷溅，不做脏乱墨汁爆炸，不把水墨做成灰雾糊片。尽量贴近参考里雪山、枝干与建筑的笔法和墨韵。
Composition/framing: 完整的纵深山野场景，不是空白纸。山石、梅枝与远山的运动方向彼此连贯，近景墨重、远山墨淡；画面中上部保留宽阔清爽但仍有淡远山层次的留白，方便将来另行设计UI文字与控件。大面积清冷白雪和浓黑前景形成鲜明对比，驿站保持小而可辨，不成为主建筑展示。
Color palette: 黑、白、冷灰；只有少数梅花与花瓣用朱红，任何其他区域不加彩色。不要米黄、棕黄仿古纸、暖色滤镜、彩色光照。
Constraints: 一张候选，场景背景探索图；没有人物、英雄或角色立绘；没有竞技场、擂台、圆形平台、棋盘或神殿；不借用新世界观设定；没有文字、标题、Logo、按钮、边框、设备模型或水印。不要画成旧宣纸山水蓝牙页面，不在已批准旧图上改画。
