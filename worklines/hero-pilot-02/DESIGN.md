# 岑缨 · 引缆人｜EXP-HERO-002｜设计v1
状态：`delegated_designer_decision`，本轮自主定稿待工程证据检验；不登记正式H编号。世界归属遵循用户本次明确要求：WORLD-EXP-01／世界E悬衡界。
## 人物
岑缨是处理断桥和失衡泊位的引缆救援者。她擅长把一条绷紧的缆接到仍然可靠的支点上，只拉动关键的一段，让旁人有时间撤离；不能停止整片台地漂移，也不能稳定控制新世界的时空异常。
一次救援里，她亲手放掉了价值远高于自己家产的货架，保住桥上仍来得及撤离的人。她没有因此变成英雄传说中的完美人物：判断很快，有时也太快，不擅长让仍依恋旧物的人接受损失。她与司衡曾在一处货运泊位协作，知道对方值得托付一端绳索；这段有限工作交集是本轮新增创作，不倒写成过去已确认的师承或亲属。
她接受赛事邀请，是想看看别人在无法兼得时如何选择，并把新办法带回救援队。她不许诺夺冠换取某个已定奖励，也不知道真实创世起源。棋局中她是指挥平台上的英雄，人物本人不新增为棋子。
## 外观与语气
成年女性、约三十岁、结实体态、暖棕肤色；短黑发与一束锈红编发。象牙白粗布短外套、赭红旧围巾、煤灰工装裤、旧铜扣与厚手套；腰侧救援绞盘、卷缆与带陶白配重的折叠抓钩。轮廓重心偏低，动作利落；材质能看出悬衡界生活，却不复制司衡的深青长短衣片。
厚涂手绘、清楚的面部与职业轮廓；不强制水墨武侠。台词：“拉近一步，别贪第二步。”“先找稳的那一头。”“缆可以断，人先过去。”
## 核心乐趣
把对手原本安稳的一个防守位置拉开，同时把危险拉向自己的支点。对手能看见锚、目标、次数和一切几何条件，可以拆锚、挡线、换阵，或在被拉之后立即反击。发动不是进攻，不直接吃子，不额外赠送随后攻击。
## 引缆：完整规则
| 项目 | 本轮受托决定 |
|---|---|
| 类型 | II级、英雄来源、【占步】【耗费】【移置】，替代本回合唯一主行动 |
| 时机 | 己方正式回合主行动前，当前不受将；不进入应将、流舞、衍生、洗牌、降临或强制降落窗口 |
| 次数 | 每方每局最多成功2次，已用/剩余公开；不刷新 |
| 锚 | 一枚当前己方控制、明置、非将帅、地面、非无形棋 |
| 目标 | 一枚当前敌方控制、明置、非将帅、地面、非无形棋；不读隐藏真正主帅身份来筛掉表面普通目标 |
| 路线 | 锚与目标在同一横线或竖线，相距2至3格，中间所有地面格为空；空中棋不占地面路径 |
| 效果 | 目标朝锚移置恰好1格到空地；方向/终点由权威算出，锚不动，不改兵种或控制权，不揭暗，不直接吃子 |
| 空间 | 以被拉棋的公开控制方判定原有placementAllowed，尊重堡垒；不进河、不授飞行，不受普通棋种走法限制 |
| 王安全 | 先以公开棋盘模拟移置，若己将变为受威胁则拒绝；技能可以形成对敌方的将军，随后按原规则应对 |
| 秘密与落位 | 候选只读公开状态，不查暗身份或秘密陷阱；成功后调用原落位结算，beforeController记被拉棋原控制方；合法秘密风险不退次数 |
| 附着 | 状态随棋子ID，不刷新持续时间；不是普通移动，不触发普通移动专属收益 |
| 失败/重复 | 公开非法、旧revision、错误窗口等拒绝，原状态/资源不变；重复actionId不重复扣费 |
| 历史 | 准确记录被拉棋from/to、II级和占步；H05不能把它当普通俗手；H06完整快照恢复本英雄当时资源，H06自身一次限制仍在 |
| 终局 | 已终局不可发动；原子结算/直接消灭优先。存在合法引缆时不只凭普通移动无路判困毙 |
首发只适配本机混乱象棋完整引擎；显式heroPilot2=1可选，默认19人池不变。与司衡同世界不要求两名试点代码先互相合并。
## 强度假设与待验
一手与一格必须产生实际结构收益，否则不值得发动。初判优先检验拆马开车线、炮架变化、敌车被拉后反吃锚、无效果回位，以及红黑镜像。当前尚未以实跑数据声称已合理均衡；实际证据将在BALANCE/VALIDATION绑定。岑缨和猎人/死骑不能同方同时选，合成落位兼容测试不能宣称是常规的“自己设陷阱再拉人”连招。
