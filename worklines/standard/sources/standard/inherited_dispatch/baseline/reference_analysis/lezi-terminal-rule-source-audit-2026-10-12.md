## 2. 确实需要补齐的规则字段

| ID | 缺口 | 为什么会改变裁定 |
|---|---|---|
| TER-R01 | 什么算同一局面 | 棋盘位置和行动方相同，技能次数、资源、冷却、附着状态、地面对象、隐藏身份等仍可能不同，后续行动能力也不同 |
| TER-R02 | 重复触发阈值及计数方式 | 第几次出现才触发、是否必须连续循环、第一次是否计入、按正式机会还是子行动记录均未确认 |
| TER-R03 | 长将的责任与处理 | 单方持续将军、双方交替将军、被迫应将、英雄形成的威胁以及如何要求变招/判负未确认 |
| TER-R04 | 长捉的精确定义 | 能攻击不必然等于有效追捉；目标是否同一棋、能否合法吃到、是否受保护、是否双方互捉、暗棋/承载棋如何识别都需规定 |
| TER-R05 | 普通循环何时判和 | 单方长将/长捉是否从重复和棋中排除、双方均有责任时怎么处理；不能先用一个“重复即和”覆盖全部分支 |
| TER-R06 | 比较时点与历史段 | 按正式行动的哪个已闭合时点比较；洗牌/回溯是否分段、能否跨时间断点计数，需与既有原子及时间线语义衔接 |

已确定的边界无需重问：不能在尚未闭合的流·舞/突袭/同批死亡中间状态直接结束对局；正式终结后停止后续普通切换、刷新和玩家决策。新增重复裁定必须服从这些已确认边界。

暂未新增“无进展N步”“双方协商和棋”等功能；在本次来源中未取得具体批准，也不以常见象棋惯例默认加入。
