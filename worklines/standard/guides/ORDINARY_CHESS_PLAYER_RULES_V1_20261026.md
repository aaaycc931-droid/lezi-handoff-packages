# 《乐子象棋》普通象棋｜玩家规则简明说明 V1

> **状态：已确认设计的通俗说明稿（2026-10-26），不是已上线游戏说明，也不是新的规则批准。** 普通模式英雄与畸变尚未通过完整适配/引擎资格化，正式联动棋谱和真实游戏验收仍未运行。以下只帮助理解**已确认**的适用规则；遇到复杂叠加，以原确认的精确适用条件和当前共享正文为准。所有英雄/畸变条目的列出都不代表此刻客户端已开放选择。

## 1. 从普通象棋开始

这不是把揭棋的暗棋洗牌照搬过来。普通象棋使用**9路×10行、32枚棋子全明、标准固定初始布局**，双方各16枚。士/仕遵守本方九宫范围、象/相不过河；其他常规棋法、占格、蹩马腿、塞象眼、炮架、将帅照面与合法应将约束保持。不会因为棋子全部明置就自动知道猎人陷阱、风的真实主帅宿主、天空上将秘密培养对象等**英雄秘密**。[来源：模式基础](../rules/shared/09_CURRENT_GAME_MODES.md)｜[普通覆盖](../modes/standard/CURRENT_RULES.md)

设计的对局流程依次是：选本机/蓝牙方式 → 选择英雄（通常预留60秒）→ 秘密猜拳确定先手（通常预留30秒，平局重猜）→ 创建棋盘与抽取本局畸变 → 公布畸变并处理英雄入场 → 英雄准备阶段（至多60秒）→ 正式行动。通常正式行动限时60秒；特定英雄、宿命和端侧流程可能有独立时间规则。这里是**规则设计流程，不表示这些界面/联机操作已在普通模式完成实装**。[来源：共同回合流程](../rules/shared/01_CURRENT_RULES.md)

**一局原则上只有一项生效畸变**；抽取受模式候选池、英雄前提及未定精确概率限制。两名英雄均须符合当前普通规则，不能因本说明同时介绍两个畸变，就把它们叠在同一局。[来源：畸变总表](../rules/shared/03_CURRENT_MUTATIONS.md)

## 2. 一回合应该怎样操作？

一个正常正式回合可按以下顺序理解：

1. **回合开始**：结算到点的训练、冷却、资源、降临与其他开始效果。
2. **主行动前窗口**：若英雄或本局畸变有允许的发动机会，在规定条件下选择使用。
3. **主行动**：通常选一枚合法棋子完成一次【移动】或【进攻】；某些技能会【占步】，直接用掉这一次正常主行动。
4. **本次行动全部结算**：路径碾碎、终点防护、落位陷阱、返回、死亡、附带效果与王安全等，按来源完成同一行动原子后再判定结果。
5. **回合结束**：结算持续效果或感染等回合末效果，依法切换行动方。

**【移动】**是不主动把其他棋作为攻击目标的棋盘行动；**【进攻】**是主动以敌棋/其他合法目标造成杀伤的行动，并不保证目标最终被消灭。**【占步】**是技能花掉这回合原本的正常行动机会，例如祈求迦拉克隆；**【额外】**或技能附带行动不是多获得一个完整正式回合；**【移置】**不是普通移动。不要把所有叫“再走一下”的行为都当成新回合。[完整术语](../rules/shared/01_CURRENT_RULES.md)

**将军不等于当场胜利。** 普通将军需要合法应将；确实无合法应对才会按裁判规则终结。陷阱、感染、碾碎、时间崩坏等也可能直接消灭将帅，但同一行动内需先完成已承诺的效果并关合原子，然后依法判断胜负；同一原子最终双方真将帅均消灭属于两败俱伤。不要把系统看到“将军”的中间画面理解成已经结算终局。[将军／消灭／终结](../rules/shared/01_CURRENT_RULES.md)

### H21 五种降临形态，怎么理解？

H21在选英雄时即秘密锁定五形态之一，英雄入场时与其形态一起公开。四次祈求不必连续，每次花掉一手；第四次只出现预兆，**不会当场免费降临**。经对手一个完整正式回合且对局未结束后，下次己方正式回合开始降临，正常主行动仍保留：

- **梦魇**：从合格己棋选择最多4枚移置到空地面格，普通士/象区域及“完整部署不能因此将军”等条件仍适用。
- **无敌**：随机最多4枚合格己方非将帅得到【龙爪】和一次【龙鳞】；龙鳞只按规定阻止某些进攻/碾碎致死，不能笼统理解成万能无敌。
- **邪火**：按四次独立随机兵、士、象、马种类生成真正新棋，放在合格己半场空格；可放置数量不足则按已确认规则处理。
- **风暴**：在己半场生成至多两枚风暴元素，各有一次特殊突袭；**初始突袭不能造成将军**，以后的常规有效威胁依规则判断。
- **讳言**：从敌方实时合格的已揭示非将帅棋中随机消灭最多4枚；不是玩家点名任意4枚。

[完整H21身份、祈求与五形态来源](../rules/shared/02_CURRENT_HEROES.md)。关于无敌的“随机至多4枚”，本线已写抽取与重放设计合同，但**没有完成普通模式真实RNG/自然棋谱验收**。

## 4. 畸变速览（当前普通模式的差分）

| 畸变 | 本局改变了什么 | 玩家最容易误解的地方 |
|---|---|---|
| **M01 铁马** | 原本正常马步的马腿若存在地面棋，按来源先尝试【碾碎】再走马步 | 目标合法性不免除、己方马腿也可能被处理；地面无形也占马腿 |
| **M02 堡垒** | 对敌方九宫施加进入【封锁】 | 宫外敌棋不能用正常进入/复活落位等绕过；在宫内者可在允许情形下行动离开；特定来源返回有专属例外 |
| **M03 暗影之舞** | 双方各得到一套来源独立的类似潜行者刺杀机会 | 若英雄本来也是潜行者，两套来源独立，但**不能同时叠两个潜行来源** |
| **M04 战车** | 普通合法地面车可向同线的实际合法敌目标发起“隔一枚地面棋的【进攻】”：尝试碾碎路径，再处理终点 | 恰有一枚地面路径才适用；0枚按正常车、≥2枚不能这样进攻；不允许对空终点发动，不直接普通吃将帅 |
| **M05 亲征** | 公开承担将帅规则的棋获得横竖畅通长距离行动，可出九宫、跨河 | 依然需终点合法安全、不能穿地面棋；不是随意吃将帅或免疫陷阱 |
| **M06 骑兵** | 普通开局双方**原始两匹明马**立即增加一格短步：己半场只能前一格，敌半场前/左/右一格 | 保留正常完整日字马步，不是马步之后免费加走；后来新生马不自动替补 |
| **M07 混乱** | 共享其他模式保留设计 | **暂不进入普通象棋畸变池**，不对32枚明棋随机变色 |
| **M08 尖斜** | 普通地面兵卒过河后，从横向一格改为**前、左前、右前各一格**（移动和进攻使用相同几何） | 过河当步仍按原前一步；回己半场按当下起点恢复只有前一步；到底线不晋升、不自动消灭 |

### M04 战车与龙鳞：只需记住的三条

1. **路径和终点分别结算。** 如果中途路径棋已经真实被碾碎，终点后来挡住进攻，也不会把路径死亡“倒带”复活。
2. **路径棋有一次龙鳞**：在已批准的精确普通进攻情形下，路径棋耗鳞留位，战车仍继续原合法进攻处理终点；不是必然停止。
3. **H02潜行者联动**：合法后续刺杀可读取战车一路径几何，但不能把刺杀特权加在路径棋上；发动当回合终点单龙鳞拦截和已持刺杀机会的终点拦截，**对H02使用次数的后果不同**。

这些仅在原来源限定的合法地面车、非将帅目标、防护组合、返回和王安全前提下适用，其他复杂防护、秘密承载者、飞行与历史不自动按本表判断。[共享H02](../rules/shared/02_CURRENT_HEROES.md)｜[M04限定确认](../rules/confirmed/M04_PATH_DRAGON_SCALE_CONTINUATION_CONFIRMATION_20261017.json)｜[H02发动终点鳞A](../rules/confirmed/H02_M04_ACTIVATION_ENDPOINT_DRAGON_SCALE_CONFIRMATION_20261019.json)

## 5. 隐藏宿命 D01「时光之末」

它**不是普通畸变池里可主动指定的一项常规畸变**。仅当双方恰选诺兹多姆与姆诺兹多（阵营不限）时，才可能在传说内部候选中出现；不保证必定抽到。未触发时两位英雄分别照常使用回溯／扭曲时间线。触发后，双方第一正式行棋回合是**75秒**，技能改成两套阵营专属规则：

- **诺兹多姆阵营**：普通模式开局的5枚兵卒作为已现身、公开锚点的时光勇士；整局有**5次沙漏**。合法使用可以让已现身勇士在各自锚点合法时回归/复活、净化污染，并让合格存活无限龙装填。每次按完整次序结算。**零勇士实际回归也扣1次**；合法窗口内可逐次使用多次，不能免费重试。
- **姆诺兹多阵营**：普通模式开局的5枚兵卒作为已现身、公开对应的无限龙；符合条件的存活无限龙每枚弹药上限1，每个该方正式回合**全军最多投一枚**，曼哈顿距离不超过3。投弹后本回合正常主行动仍在；**当前受合法将军时不能先投弹再依靠主行动解将**。
- **时空扭曲／时间崩坏**：炸弹在目标格留持续污染，合法落在污染格上的诺兹多姆棋可能获得时间崩坏。污染并不是实体炮架或绝对护罩；棋可能通过合法进攻进入。时间崩坏到期或被净化、合法离开前的完整条件以宿命正文为准。
- **王安全**：沙漏在某些受将局面可作为合法应将尝试，但要先对**整次沙漏完整结算后的王安全**做预检；若实际不能解除己方受将，则不提交、不扣次数。不能先提交一个不安全的沙漏，再指望下一次沙漏救回来。

## 6. 八个常见误解

1. **“全明棋局没有秘密了？”** 错。棋子本体公开，不等于敌方猎人陷阱、风真正主帅宿主或天空上将受训者公开。
2. **“无形就不会挡车／做炮架？”** 错。只要该棋仍在地面，就照常占格、挡路、做炮架、马腿、象眼。
3. **“飞行棋可以隔地面棋进攻？”** 错。飞行本身**不能进攻**，M04也没有给飞行战车新增进攻资格。
4. **“见到将军就立刻结束？”** 错。普通将军是威胁；正常应将、来源特殊终局、原子闭合分别判断。
5. **“技能不占步就白送一个新的完整回合？”** 错。不占正常主行动不等于额外完整回合，也不刷新原截止或自动增加技能机会。
6. **“H14夜／M07混乱还写在共享表，所以普通能抽到？”** 错。两者已明确**普通模式暂不入池**。
7. **“龙鳞总能保命／挡两次？”** 错。只在特定进攻本体终点击杀或碾碎致死来源作用，通常只有一次；不能免疫陷阱、感染等全部死亡。
8. **“这些说明意味着普通英雄畸变已经能玩？”** 错。它们是已确认的玩法**设计**，而非当前实现、游戏客户端、联网或正式测试通过的证明。
