# 普通象棋评分模型｜人工校准案例

状态：`synthetic_invariant_tests_only`。全部`u`是任意一致标尺上的**人工假设效用**，既不是PU、百分制分、胜率、正式英雄分，也不是实战观测。除规则明确的约束外，具体数字仅用于检查顺序/算术。各例相互独立，不强行加成一个英雄分数。

| ID | 测试性质 | 构造 | 应得结果 / 不变量 |
|---|---|---|---|
| T01 零效果 | 无能力与有能力在同一局面行动轨迹/资源完全等价，效用差0 | `ΔU=0`，五维新增都0 |
| T02 占步单调 | 相同合法结果毛收益0.60u；版本A无主行动机会成本，版本B额外牺牲最佳正常行动机会0.25u；其余严格相同 | A净0.60u，B净0.35u；B不得更高 |
| T03 触发概率 | 合法、收益非负且其余条件一致；成功收益0.80u，失败0；版本低触发p=0.20、高触发p=0.65 | 低0.16u，高0.52u；高不低于低；不表示真实触发率 |
| T04 信息无效 | 等概率环境A/B；动作X在A/B各得3/2u，Y在A/B各得2/1u；完整信息不收费 | 无信息选X得2.5u；有信息仍选X得2.5u；EVSI=0，尽管环境已分辨 |
| T05 单次吃子 | 一次行动的最终唯一增益在同一U中是1.2u，技能宣称“能额外进攻”但无独立额外节奏 | 事件仅归子力一次记1.2u；行动维度该事件残差0；总仍1.2u而非1.2+附加 |
| T06 一次救将 | 能从必败分支挽救而使终局期望增益0.9u；“保住一枚棋”“多一步应将”完全属于同一因果事件 | 主归终局0.9u；子力/行动该事件残差0；总0.9u |
| T07 提前终局 | 当前来源兑现0.8u后立即终局；原计划下一回合再兑现0.5u，但该回合不存在 | 总0.8u；不得加0.5u |
| T08 互斥规避 | 对手不规避直接兑现概率0.25、效用2u；规避概率0.60、对手替代策略代价对我1u；无影响概率0.15、0u | 概率合计1；期望`0.25×2+0.60×1+0.15×0=1.10u`，不可每叶重复加兑现和规避 |
| T09 H11窗口互斥 | 在人工一次对局中A窗口发动概率0.4，未发动后B条件发动概率0.5 | 实际发动总概率`0.4+0.6×0.5=0.7`，两窗口绝不能当两次技能独立计；窗口B占用该黑方正式回合但不做尚未发生普通开始结算 |
| T10 负净效用 | 两互斥叶：概率0.75收益+0.5u，概率0.25收益−2u | 净`−0.125u`保留负值，不取绝对值/直接截0；正式显示交主对话 |
| T11 额外选择但无价值 | 增加一次合法附加机会，但受当前规则限制没有优于现有可执行方案的动作（可以不使用） | 净新增0，不按“多一步”自动得行动分 |
| T12 标准合法性 | 仕不能被假定出九宫、象不能假定过河；若设想来源动作依赖未确认突破空间规则 | 基础合法动作集合不包含越界动作；依赖例外者`blocked_pending_rule`，不能生成伪触发率 |

**灵敏度样例**：若纯人工来源从己方第16正式回合开始每回合有一次（假设全部合法、无冷却、对局恰在L回合后结束），L=25、30、35对应10、15、20次。改变`L`只改变可得机会数上界；不证明真实局长概率、实际期望收益，且如果更早终局必须以真实条件生存截断。

**类型错误防范**：PU、效用u、结果概率和原始维度分不得直接相加。信息价值若已表现为杀子/救将，则在信息维度记未重复的剩余部分；没有“看到秘密就加分”的固定兑换率。
